Fair questions

Is there a subscription?▾

No, and there never will be. You top up a balance; calls deduct from it. Credits never expire. When you stop using Fetch42, you stop paying — and your unused balance is refundable on request, any time.

What data can Fetch42 access?▾

Publicly available data only — public profiles, public posts, public video transcripts, search results. Structured into one clean schema per capability.

What happens when a call fails?▾

You pay nothing. We first retry through a different upstream source automatically; if everything fails, the call is free and logged. Only successful responses are ever charged.

How do I plug this into my agent?▾

Today: REST with your API key — one curl to try it. Next: an MCP endpoint, so Claude Code, Cursor or any MCP client discovers all Fetch42 tools with one config line.

How is my agent kept from overspending?▾

Prepaid balance (you can never go negative), per-key daily budget caps (default $5/day), and the exact cost plus remaining balance on every response.

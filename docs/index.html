MCP server

All 250+ endpoints are also MCP tools (Streamable HTTP) — same key, same prices, exact cost in every tool result. One config line and Claude Code, Cursor or any MCP client sees the full catalog.

# Claude Code
claude mcp add --transport http fetch42 https://api.fetch42.ai/mcp \
  --header "Authorization: Bearer fk_live_…"

# Any MCP client (generic JSON config)
{ "url": "https://api.fetch42.ai/mcp",
  "headers": { "Authorization": "Bearer fk_live_…" } }

Rate limits & concurrency

  • 60 requests/minute per key — a token bucket, so short bursts are fine. Beyond it you get a clean 429 with retry_after_s.
  • Concurrency — no hard cap; run parallel calls freely within the 60/min budget. Slow scrape endpoints can take up to 45s, so ~10–15 in flight is a practical ceiling.
  • Need more? Rate limits are per key and raised on request — email us, usually same-day.
  • Optional per-key credit limits and expiry are yours to set in the dashboard; the prepaid balance is always the hard stop.

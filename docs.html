API Reference

One base URL, one key, one prepaid balance across 250+ endpoints. The most-used are documented below; anything else is routed on request. Every response is normalized JSON with a meta block carrying its exact cost. Failed calls are never charged.

Base URL & auth

Base URL   https://api.fetch42.ai
Auth       Authorization: Bearer fk_live_…

$ curl "https://api.fetch42.ai/v1/tiktok/profile?handle=stoolpresidente" \
    -H "Authorization: Bearer fk_live_…"

TikTok

GET/v1/tiktok/profile

params: handle

Profile: display name, bio, followers, following, likes, video count, verified.$0.005

GET/v1/tiktok/posts

params: handle, cursor?

Recent posts: caption, created_at, likes, comments, shares, views, thumbnail. Cursor-paginated.$0.005
